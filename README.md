# AI 视频素材 → 剪映草稿 0.3.0

Windows 本地工具，支持单集和批量分集。每集素材按文件名自然排序，首尾连续地放在一条主视频轨上，默认 1080×1920、30fps。

## 运行环境与安装

- Windows 10/11 64 位；剪映专业版准确版本 `11.3.0.14362`。
- 公司工位无需 Python，解压整个 `AIDraftBuilder-0.3.0-win64.zip`，运行其中的 `AIDraftBuilder/AIDraftBuilder.exe`。
- 必须保留 `_internal` 和程序目录中的其他文件，不能只复制 EXE。
- 支持本地固定素材目录；素材通过绝对路径引用，生成后不要移动、重命名或删除。
- 默认安装位置为 `C:\Program Files\JianyingPro\Apps\11.3.0.14362\JianyingPro.exe`，草稿位置为 `%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`。未满足时显示错误；本版不支持自定义安装位置或草稿目录。

## 单集与批量操作

1. 完全退出剪映，生成期间保持关闭。
2. 单集模式：点击“浏览素材”，选择该集任意一个视频，软件识别同目录全部视频；填写草稿名。
3. 批量模式：选择总目录。直属子文件夹各是一集，例如 `短剧/第1集`、`短剧/第2集`、`短剧/第10集`。
4. 勾选需要生成的分集；支持全选/取消全选。可选名称前缀如 `短剧A-`，留空则直接使用分集文件夹名。
5. 点击生成。至少一集成功且任务正常结束时，默认自动打开剪映；可取消该选项。
6. 草稿应出现在剪映本地列表；若没有，完全退出并重新打开剪映。仍无记录时查看任务日志，不要反复生成同一批。
7. 失败集修复素材后可点击“重试失败分集”；此按钮只处理上次任务失败集，不重复生成成功集。
8. 需要停止时点击“完成当前集后停止”；关闭窗口也可等待当前集结束后退出。剩余集标“未处理”，可重新勾选。

同名草稿使用 `名称 (1)`、`名称 (2)`，不覆盖旧草稿。重试按钮保留原任务的前缀与目录；如果要更改命名，使用普通勾选生成。

## 素材与排序

- 支持 mp4、mov、mkv、avi、webm；支持扩展名不代表其中所有编码都已在剪映验证。
- 只识别分集目录顶层的视频，不递归；批量忽略以点开头的目录、符号链接和目录连接。
- 数字自然排序：`1、2、10`；`001、002、003`；`镜头1、镜头2、镜头10`。
- 中文文字采用确定的字符串顺序；不将“一、二、十”等汉字当作数字解释。建议使用 `第01集` 格式。
- 空集默认不勾选，显式选择时跳过。不可读分集单独显示原因。
- 零时长、无视频轨、解析异常、文件变化使该集失败；其他集继续。
- 媒体读取或临时构建 120 秒没有实际进展时结束该集。大小和修改时间检查不能保证已复制文件全帧可播放，剪映播放效果仍需人工验收。

## 任务安全、日志与核查

- 同一草稿目录一次只允许一个工具任务生成；每集安装和注册前检查剪映状态。
- 每次注册保存原索引字节备份；根索引发生外部变化则停止后续写入，不覆盖外部内容。
- 进程、权限、磁盘空间、索引等任务级异常会停止后续分集；已成功的草稿保留。
- 安装前发生异常，只清理本次拥有的临时目录。最终草稿目录不会被自动删除。
- 安装后异常或强制退出时会保留现场。重启工具通过明文根索引的草稿 ID 与目录核对：存在则认定成功，其余标“待核查”，禁止自动重试该素材目录。
- 日志：`%LOCALAPPDATA%\AIDraftBuilder\logs`，单份最大约 5MB，保留 5 份轮转备份。
- 逐集记录：`%LOCALAPPDATA%\AIDraftBuilder\tasks`，包含源目录、实际草稿路径、草稿 ID、阶段、结果、时长和耗时；结果记录不自动删除。
- 根索引备份：草稿根目录旁 `.ai-draft-builder-backups`，不自动删除或整份回滚。
- 点击“打开日志目录”可进入本地数据目录。日志含本地路径，发送排障资料前按公司要求检查。

“待核查”由维护人员处理：关闭剪映并停止其他生成任务，保留原记录；核对草稿列表与实际目录。若草稿已注册且目录存在，重启工具自动确认成功。无法核对时联系维护人员；不要手工删除记录、草稿或覆盖索引来绕过限制。本版没有自动修复或解密功能。

## 源码运行与测试

使用 Python 3.12：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m ai_draft_builder
.\.venv\Scripts\python.exe -m pytest
```

真实媒体测试默认读取 `test_materials/公开单集五镜头`。也可设置 `AIDRAFT_TEST_MEDIA` 为至少包含两个不同 MP4 的目录。媒体未提交到 Git，缺少时集成测试会明确跳过；发布必须提供真实素材。

## 构建与发布包

执行（构建不会停止旧进程；发布到固定目录前须关闭正在运行的旧版）：

```powershell
.\build.ps1 -TestMediaDir 'D:\测试素材'
```

构建先跑完整测试，再在独立目录打包并用真实视频验证工作进程。通过内容与隐私检查后，把旧版移至 `dist/backups`，新版放到 `dist/AIDraftBuilder`，验证主窗口启动后制作 `dist/AIDraftBuilder-v0.3.0-win64.zip` 及 SHA-256 校验文件。ZIP 包含整个运行目录、TESTING.md 和第三方许可证，不包含源码、素材、虚拟环境或开发机记录。自测只生成隔离目录，不注册进剪映。

试用前执行 [工位验收清单](ACCEPTANCE_CHECKLIST.md)，本地验证与未完成项见 [兼容性记录](COMPATIBILITY_TEST.md)。需在至少两台工位验收后才能标为正式投产通过。

## 限制

仅支持固定剪映版本、本机素材及标准安装路径。未支持 NAS、跨电脑素材搬迁、后台运行剪映时生成、多版本兼容、字幕、配音、BGM、自动剪辑、自动导出或自动更新。未修改既有草稿，不读取或解密剪映保存后的草稿。
