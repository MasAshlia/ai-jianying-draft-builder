# AI 视频素材一键生成剪映草稿 MVP

面向 Windows 剪辑师的本地工具：支持单集生成和批量分集生成。每集视频按文件名自然排序，连续放在同一条主视频轨上。

## 已锁定环境

- Windows 10/11 64 位
- Python 3.12
- 剪映专业版 `11.3.0.14362`
- 草稿主文件 `draft_content.json`
- `pyJianYingDraft==0.3.0`

程序会检查剪映版本。不是 `11.3.0.14362` 时会拒绝生成，不会猜测兼容性。

## 直接运行构建产物

打开：

```text
dist\AIDraftBuilder\AIDraftBuilder.exe
```

### 单集生成

1. 完全退出剪映，包括仍在后台运行的剪映进程。
2. 点击“浏览素材”，在 Windows 文件窗口中查看视频图标和名称，选择该集中的任意一个视频。程序会自动识别并列出同文件夹内的全部视频。
3. 确认草稿名称，点击“生成剪映草稿”。
4. 显示成功后程序会自动启动剪映，草稿应直接出现在本地草稿列表。
5. 打开草稿，检查片段顺序后即可继续剪辑和保存。

### 批量分集生成

总素材目录中的每个直属子文件夹代表一集：

```text
短剧名称\
├─ 第1集\
│  ├─ 1.mp4
│  └─ 2.mp4
├─ 第2集\
│  ├─ 1.mp4
│  └─ 2.mp4
└─ 第10集\
   └─ 1.mp4
```

1. 完全退出剪映。
2. 在软件中选择“批量分集”。
3. 点击“选择总目录”，选择示例中的 `短剧名称` 文件夹。
4. 检查分集名称、顺序和视频数量，点击“批量生成剪映草稿”。
5. 软件按 `第1集、第2集、第10集` 的顺序逐集生成，并在全部完成后只启动一次剪映。
6. 某一集失败不会影响其他分集；完成窗口会逐集列出失败或跳过原因。

批量模式不递归：只有总目录的直属子文件夹会被视为分集。没有支持视频的子文件夹会显示为“跳过”，不会创建空草稿。

素材通过绝对路径引用，不会被复制。生成后不要移动、重命名或删除源视频，否则剪映会丢失素材。

## 素材规则

- 只扫描所选文件夹的顶层，不扫描子目录。
- 支持：`mp4`、`mov`、`mkv`、`avi`、`webm`。
- 其他文件会被忽略。
- 使用自然排序，例如 `1.mp4`、`2.mp4`、`10.mp4`；`001.mp4`、`002.mp4`、`003.mp4`；`镜头1.mp4`、`镜头2.mp4`、`镜头10.mp4`。
- 任何一个支持扩展名的视频损坏、零时长或没有视频轨，整次生成都会在写入草稿前失败，并指出具体文件。

## 草稿位置与安全策略

默认草稿根目录：

```text
%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft
```

- 同名草稿不会覆盖，会依次命名为 `名称 (1)`、`名称 (2)`。
- 草稿先在应用专属临时目录生成并校验，再安装到草稿目录。
- 最后才备份并原子更新 `root_meta_info.json`。
- 失败时只清理本次创建的精确路径，不删除已有草稿或素材。
- 每次注册前的根索引备份位于草稿根目录旁的 `.ai-draft-builder-backups`。

## Windows 打包

```powershell
.\build.ps1
```

产物为 `dist\AIDraftBuilder` 目录。采用 `onedir + noconsole`，运行时必须保留整个目录，不能只复制 exe。

## 已知限制

- 仅支持剪映专业版 `11.3.0.14362`。
- 不读取或解密已有草稿；只创建新的明文草稿，首次被剪映接受并保存后由剪映自行处理。
- 不复制素材，不支持素材迁移。
- 不递归子目录。
- 批量模式按顺序串行生成，不提供分集勾选、暂停、取消或并行生成。
- 生成成功后只负责启动剪映；不控制剪映界面，也不自动导出。
- 字幕、配音、BGM、转场、滤镜、特效和时间线编辑均不在 MVP 范围。
- 真实剪映打开验收尚需一集真实 AI 视频素材。当前兼容性状态见 [COMPATIBILITY_TEST.md](COMPATIBILITY_TEST.md)。
